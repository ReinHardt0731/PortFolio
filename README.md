## Overview

The website presents Rexus's engineering work through a combination of detailed reports, interactive 3D models, technical drawings, project case studies, Blender animations, certificates, and professional qualifications.

Its central message is that aircraft design is a connected process: performance requirements lead to sizing and analysis, analysis informs geometry, and CAD and drawings communicate the final result.

## Technical Drawings

### GANNET XT0731 Aircraft

The main featured project is a detailed aircraft CAD assembly with:

- 3D assembly view
- Front-view drawing
- Side-view drawing
- Top-view drawing
- 17 total technical drawing sheets across the site

The project also includes an interactive three-panel comparison of the Gannet aircraft in:

1. Shaded CAD form
2. Mesh form
3. Simulation form

The aircraft case study follows the design process from performance requirements to an optimized wing:

- **Airfoil selection:** Balancing lift, drag, thickness, pitching moment, angle-of-attack margin, and structural needs across wing sections.
- **Propeller and excess power:** Connecting propeller efficiency and advance ratio to climb capability.
- **Requirement-based sizing:** Using stall speed, maximum speed, takeoff, climb rate, and service-ceiling constraints to identify feasible wing and power-loading limits.
- **Wing optimization:** Comparing taper ratio, wing twist, and span distribution using Response Surface Methodology and aerodynamic response data.

The Gannet study reports a maximum allowable wing loading of 14.89 lbf/ft² and a maximum power loading of 8.28 lbf/hp.

## Website Design and Interaction

### GUI Structure

The website is structured as a long-form, single-page portfolio with a fixed visual system and a clear engineering-technical hierarchy:

1. **Site header**
   - A compact "Rexus Gan" wordmark
   - Navigation for CAD work, profile, skills and tools, and selected projects
   - A direct link to the Fulcrum project

2. **Hero section**
   - A left-aligned introduction and portfolio tagline
   - Primary and secondary call-to-action buttons
   - A large interactive landing gear model on the right
   - A shaded/wireframe comparison divider and reset view control

3. **Technical work section**
   - Section and project headings
   - A featured GANNET XT0731 aircraft assembly
   - A three-way interactive CAD, mesh, and simulation comparison
   - Expandable design-study cards covering airfoil selection, propeller performance, sizing, and wing optimization
   - Technical specifications and category navigation
   - A grouped technical-drawing gallery for aircraft views, landing gear, and dimensioned part studies

4. **Profile section**
   - A brief professional introduction
   - Résumé download and email actions
   - Education and core-skill cards
   - A student organization and leadership timeline

5. **Skills and tools section**
   - A grouped software directory
   - Separate categories for CAD and modeling, analysis and simulation, and documentation and data
   - Logo-based cards that link to the corresponding tools' websites

6. **Selected projects section**
   - Alternating image/model and text layouts
   - Propeller, aircraft-pipeline, UAV, and Fulcrum project cards
   - Goal, process, and takeaway summaries
   - Expandable technical details
   - Interactive 3D viewers, PDFs, GitHub links, videos, and live-site links
   - A separate Blender animation project grid

7. **Recognition and qualification section**
   - An animated aircraft stage
   - Departmental awards
   - Hackathon certificate gallery
   - A licensure examination results card

8. **Closing and footer**
   - A concise "Design. Analyze. Build." closing statement
   - Direct email contact
   - Back-to-top control
   - Résumé, Fulcrum, LinkedIn, GitHub, and email links

The interface uses a dark technical theme with large grid-like background patterns, thin engineering-rule borders, monospaced metadata labels, muted navy surfaces, and lime-colored highlights for active elements and calls to action.

The portfolio uses a dark aerospace-engineering visual style with:

- Technical-grid backgrounds
- Navy, charcoal, and pale-lime accent colors
- Monospaced technical labels
- Large editorial typography
- Interactive model viewers
- Split-screen shaded and wireframe comparisons
- Expandable project case studies
- PDF drawing dialogs
- Embedded videos and external project links

The implementation is primarily built with HTML, CSS, JavaScript, Three.js, GLTF models, and PDF preview functionality. Interactive 3D viewers support orbiting, zooming, panning, synchronized animation, loading indicators, reset controls, and accessible keyboard-operable comparison dividers.
